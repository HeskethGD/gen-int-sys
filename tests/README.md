# Verification

Run from the repository root after installing the dependencies described in the [root README](../README.md):

```sh
python -m pytest -q
python -m marimo check code/*.py
```

The tests execute all eight notebooks as well as checking their mathematical functions. The notebook structure check is a separate command.

## Framework checks

`test_framework.py` checks notebooks 01–03.

The checks cover arbitrary symbolic coefficient functions P,Q for weight vectors `(1,)`, `(2,)`, `(1,2)`, `(1,-2)` and `(1,1,1)`, the off-level residuals underlying the selected-level reduction, commuting power invariants, and exact regular and constant-power examples. They verify that a constant root of the scalar equation alone does not guarantee mode reconstruction, and that constant powers can coexist with nonconstant modes. They also check the inverse construction, common-factor and exponential/Möbius mixing equivalences, and the total-phase correction. Mixing equivalences are checked on the selected energy level; the tests also demonstrate that equivalence need not hold off that level.

An independent 90-digit evaluation compares derivatives of explicitly corrected modes against derivatives of the original unreduced phase Hamiltonian at three points. It requires scaled residuals below 1e-55 and checks that uncorrected modes do not pass the same comparison. This is a local equation-residual check, not a numerical trajectory integration or a claim of global continuation.

General symbolic arguments remain in the paper; finite weight-vector checks do not replace them or establish independence on degenerate loci.

## Example verification

`test_examples.py` covers notebooks 04–08. It checks the representative polynomial weight families, square-factor normalization, extended Euler restriction and nine Fermat/beta cases. For the logarithmic section it checks Sergyeyev's integrals and transformed equations, the explicit Lambert-W equation, Lotka–Volterra, the PT logarithmic conservation law and scalar equation, the principal inverse-sine sign condition, the constructed three-mode change of variables and the two-mode polynomial/scalar equations. These checks do not claim a global branch-continuation theorem or independently verify the entire PT canonical coordinate transformation.

Rational inverse laws are checked by differentiation, and denominator clearing is checked only on the selected level. The Bessel and modular numerical vector fields are compared off level against high-precision derivatives of their full Hamiltonians. Their trajectories are compared with inverse-function and theta-constant solutions. The modular tests also check theta continuation, the lambda ODE and the Darboux–Halphen map.

The example-notebook checks also require recognised display-math elements and bracket delimiters in source.

## Numerical settings and limits

The Bessel trajectory test uses DOP853 with `rtol=1e-11`, `atol=1e-13` and `max_step=0.05`, stopping at 98% of the selected inverse branch before its critical endpoint. The tests allow `1e-7` for mode, modal-power and absolute Hamiltonian errors, and `1e-11` for the inverse-function residual.

Notebook 07 and the manuscript use `alpha_1=alpha_2=1`, with initial modal powers `x_1(0)=5.8116` and `x_2(0)=3.4584`. Initial modes are computed from the sine-integral formulas:

```text
u_j(0) = sqrt(x_j(0))*exp(a_j*Si(b_j*x_j(0)))
v_j(0) = sqrt(x_j(0))*exp(-a_j*Si(b_j*x_j(0)))
```

These data satisfy the selected `H=0` branch without additive phase constants. The manuscript's Bessel comparison figure is generated by notebook 07's `bessel_figure` function from the full-system validation.

The modular trajectory test uses DOP853 with `rtol=1e-10` and `atol=1e-12` over real tau in `[0,8]`, sampled at 257 points. The tests allow `2e-7` for complex mode, invariant, modal-power and absolute Hamiltonian errors.

Solver tolerances and observed errors are distinct quantities. These checks supplement the mathematical arguments; they do not establish global existence or branch regularity. There is no implementation of general hyperelliptic sigma functions, and the optical hierarchy is covered by selected scalar examples rather than every optical solution or classical-mechanics projection.
